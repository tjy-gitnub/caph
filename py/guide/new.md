# 欢迎使用 Caph！
以下是 Caph 的基本使用方法。

## 如何打开、隐藏边栏？
下面任意一种方法都行：
1. 按 **快捷键 `Win`+`C`**（这原本是 Windows Copilot 的快捷键）；
2. 单击右下角 **系统托盘** 的 Caph 图标（找不到的请检查有没有被折叠，建议拖出来）；
3. 已打开时，可以按右上角 `>` 按钮隐藏边栏。

## 如何开机自启？
Caph 本身没有实现此功能，如果确需开机自启，请：
1. 按 `Win`+`R`，打开“运行”对话框；
2. 输入 `shell:startup`，回车；
3. 为 Caph.exe 创建一个快捷方式，将快捷方式放在打开的文件夹里，即可。

## 如何退出？
在右下角托盘的 Caph 图标上右键，退出。
